# digital-network-platform
# Digital Network Platform v1.0

### Промышленная событийно-ориентированная платформа (EDA) акустического течеискания, ГЕО-привязки и предиктивного мониторинга распределенных инженерных сетей города.

---

## 🚨 Назначение системы
Автоматизация процессов обнаружения, верификации и локализации скрытых дефектов/утечек теплоносителя, воды и газа на основе цифровой обработки акустических волновых пакетов и ведения предиктивных ГЕО-двойников инфраструктуры ЖКХ.

## 🛠 Ключевые возможности
* **Универсальные профили сред:** Кросс-платформенная поддержка физики газов, теплоносителей и водоканалов (`HEAT`, `WATER`, `GAS`) со встроенной адаптацией частотных диапазонов и скоростей звука.
* **Высокоточная DSP-обработка:** Полосовая 4-порядковая фильтрация Баттерворта (`bandpass`) с динамической защитой Найквиста и In-place оптимизацией оперативной памяти.
* **Математическая локализация:** Реализация взаимной корреляции GCC-PHAT с параболической субсэмпловой интерполяцией пиков и автоматическим расчетом индекса достоверности.
* **ГИС-интерполяция:** Автоматический расчет точной координаты прорыва на карте по сферической тригонометрической формуле Haversine с жесткой защитой границ физического участка.
* **Предиктивный анализ рисков:** Расчет трендов деградации приборов и комплексного износа трубопроводов с учетом их материала, рабочего давления, температуры и возраста.
* **Персистентное хранилище:** Многопоточная архитектура SQLite на 6 изолированных таблиц (`devices`, `signals`, `assets`, `alarms`, `maintenance`, `events`) с поддержкой фабрики строк `Row`.

## 📂 Структура исходного кода
Проект организован в виде модульной, слабосвязанной программной архитектуры:
* `models.py` — Слой чистых типов данных, перечислений (`Enum`) и датаклассов.
* `config.py` — Центральные настройки путей к каталогам и профили физических сред.
* `database.py` — Персистентный SQLite-слой и логирование транзакций.
* `dsp.py` — Модуль цифровой фильтрации и нормализации амплитуд.
* `analysis.py` — Спектральный БПФ-анализ (FFT) и вычисление параметров SNR.
* `localization.py` — Математическое GCC-PHAT ядро вычисления временной задержки.
* `geo.py` — Сферическая геометрия, формула Haversine и ГЕО-интерполяция точек.
* `pipeline.py` — Оркестратор последовательного расчетного конвейера обработки сигналов.
* `prediction.py` — Движок анализа трендов деградации по истории волновых карточек.
* `asset_risk.py` — Экспертная оценка комплексного риска износа по паспорту трубы.
* `digital_twin.py` — Слой агрегации цифровых двойников для экспорта в внешние GIS-системы.
* `signal_emulator.py` — Физический симулятор зашумленных волновых пакетов утечек.
* `main.py` — Финальный оркестратор приложения и запуск сквозного интеграционного теста.

## 🚀 Порядок быстрого развертывания и запуска

### 1. Системные требования
* **Интерпретатор:** Python 3.9 или выше.
* **Зависимости:** Математические библиотеки `numpy` и `scipy`.

### 2. Установка необходимых компонентов
Убедитесь, что в вашей системе установлены пакетные менеджеры `pip`, и выполните команду в терминале:
```bash
pip install numpy scipy
```

### 3. Запуск интеграционного теста
Для автоматического развертывания структуры баз данных, генерации тестовых сигналов утечки и вывода итогового предиктивного отчета ГИС-карты, запустите скрипт:
```bash
python main.py
```
