# Digital Network Platform v1.0 🌐💧

### Предиктивная ГИС-система мониторинга городских инженерных сетей, поиска скрытых утечек и прогнозирования свищей на базе машинного обучения и акустических датчиков.

---

## 🚀 Бизнес-ценность и решаемые задачи

Платформа разработана для автоматизации технологического управления и диспетчеризации Водоканалов и Теплосетей. Переводит обслуживание трубопроводов из режима «аварийного тушения пожаров» в режим **планово-предупредительного ремонта** на основе предиктивной аналитики.

*   **Снижение операционных затрат (OPEX)**: Сокращает расходы на земляные работы за счет высокоточной локализации дефектов методом взаимной корреляции (точность до 0.5–1 метра).
*   **Сокращение технологических потерь**: Выявляет скрытые микротрещины и формирующиеся свищи на ранней стадии, предотвращая потерю очищенного ресурса в грунт.
*   **Оптимизация ремонтов**: Алгоритм предиктивного анализа оценивает тренд изменения виброакустических характеристик сети и рассчитывает вероятность сквозного прорыва трубы на недели вперед.

---

## 🛠 Технологический стек (Архитектура MVP)

Архитектура построена по модульному принципу высокой доступности, упакована в контейнеры и готова к бесшовному масштабированию:

*   **Backend (API)**: `FastAPI` (Python 3.10) — высокопроизводительный асинхронный веб-фреймворк со строгой валидацией входящих ГИС-данных через `Pydantic v2`.
*   **База данных**: `PostgreSQL` + расширение `PostGIS` — промышленный стандарт хранения и обработки пространственных (географических) данных инженерных сетей (LineString, Point).
*   **Асинхронная шина событий**: Кастомный модуль `EventBus` (паттерн Publisher/Subscriber), обеспечивающий неблокирующую мгновенную маршрутизацию экстренных алармов диспетчерам при обнаружении высоких рисков свищей.
*   **Среда развертывания**: `Docker` / `Docker Compose` — гарантирует запуск всей инфраструктуры (БД, ГИС-индексы, веб-сервер) в одну команду на любой операционной системе (включая архитектуру Apple Silicon / Mac M1).

## 📁 Структура открытого конвейера проекта

```text
├── api.py               # REST API эндпоинты для веб-карты и телеметрии датчиков
├── models.py            # Строгие Pydantic-модели валидации гео-линий труб и логов датчиков
├── config.py            # Управление конфигурацией среды и безопасным подключением к БД
├── event_bus.py         # Асинхронная Pub/Sub шина распределения критических событий
├── signal_emulator.py   # Генератор/симулятор синтетических акустических сигналов утечки
├── main.py              # Точка входа приложения, инициализирующая сервер и фоновый мониторинг
├── schema.sql           # Структура таблиц базы данных и пространственных ГИС-индексов PostGIS
├── Dockerfile           # Инструкция сборки легковесного Linux-образа с зависимостями
└── docker-compose.yml   # Пульт управления для автоматического развертывания всей инфраструктуры
```
*Примечание: Математическое ядро обработки сигналов (DSP), уникальные полосовые фильтры под материалы труб и ML-модели прогнозирования защищены заявкой на патент и изолированы в приватном контуре.*

## 💻 Быстрый локальный запуск

Платформа полностью готова к тестовому запуску и демонстрации возможностей MVP.

### 1. Требования
*   Установленный и запущенный **Docker Desktop**.

### 2. Клонирование и запуск
Склонируйте репозиторий (или распакуйте ZIP-архив), откройте терминал внутри папки проекта и выполните одну команду:
```bash
docker compose up --build -d
```

### 3. Верификация работы
*   Интерактивная ГИС-документация API (Swagger UI) автоматически станет доступна по адресу: **http://localhost:8000/docs**
*   Для просмотра работы фонового эмулятора сигналов и логов валидации в реальном времени выполните команду:
```bash
docker compose logs -f web
```
